🍛 Spice Garden – Restaurant Online Ordering System
Spice Garden is a full-stack restaurant management and online ordering platform designed to help local restaurants digitize their operations and reduce dependency on third-party delivery apps. The application enables restaurants to showcase their complete menu, accept direct online orders, collect customer delivery details, and manage order statuses through a simple and efficient interface. Built using HTML5, CSS3, JavaScript, Node.js, Express.js, and JSON file storage, Spice Garden demonstrates modern web development practices including RESTful API architecture, client-server communication, responsive design, and production deployment.

📖 Project Overview
Managing restaurant orders manually can be time-consuming and prone to errors. Local restaurants lose 25-30% of their revenue to third-party delivery platforms like Zomato and Swiggy. Customers cannot see the full menu online, and restaurant owners have no direct access to customer data.
Spice Garden provides a digital solution that helps restaurants display their complete menu, accept direct online orders, collect delivery addresses, and save all order data – all with zero commission fees.
The platform focuses on helping local restaurants grow their online presence, reduce dependency on third-party delivery apps, build direct relationships with their customers, and increase average order value through complete menu visibility.

✨ Features

Display 28+ menu items across 5 different categories.
Store and manage item names, descriptions, and prices.
View all menu items organized by category.
Update menu details when necessary.
-📝 Online Ordering System
Allow customers to select items directly from the menu.
Collect customer information including name, phone number, and delivery address.
Enable quantity selection for multiple item orders.
Calculate total amount automatically based on item price and quantity.
-💰 Payment Options
Offer Cash on Delivery payment method.
Provide Card Payment option for customer convenience.
Support UPI payments through Google Pay and PhonePe.
-📊 Order Management
Save all customer orders to restaurant_orders.json file.
Track order status from pending to completed.
Maintain organized order records with unique order IDs.
View and manage all orders from a centralized system.
-📱 Mobile Responsive Design
Access website perfectly on smartphones, tablets, and desktops.
Navigate easily with touch-friendly buttons and forms.
Order comfortably from any device screen size.
-🗄️ Data Storage
Store customer orders securely using JSON file storage.
Retrieve order data efficiently for restaurant management.
Maintain structured records with timestamps and order IDs.
-🌐 RESTful API Architecture
Backend developed using Express.js.
Clean API structure for scalability.
Organized route handling with GET, POST, PATCH methods.
Efficient communication between frontend and backend.
-☁️ Cloud Deployment
Backend deployed on Render.
Frontend deployed on Netlify.
Accessible online without requiring local installation.
-🎨 User-Friendly Interface
Clean and intuitive design with Indian restaurant theme.
Easy navigation across menu categories.
Responsive and lightweight frontend experience.
-🔒 Zero Commission Model
Direct online orders with 0% commission fees.
Restaurants save 25-30% compared to delivery platforms.
Complete revenue retention for restaurant owners.
